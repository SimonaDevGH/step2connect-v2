# Scheda Pages nel CMS admin

La scheda etichettata `Pages` deve mostrare una vista complessiva dei contenuti `guides`, `news` e `library` nella lingua selezionata.

**Why:** l’utente la usa come elenco generale per controllare e gestire tutti i contenuti, non per creare pagine CMS autonome.

**How to apply:** mantenere il riepilogo filtrabile per lingua, distinguere il tipo del singolo elemento nelle colonne e indirizzare modifica, pubblicazione e archiviazione al tipo reale dell’elemento.
